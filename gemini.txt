# MCPSense — Fix Double "v" in Version Display

## Context

MCPSense is at `C:\Users\Dell\Desktop\MCPSense\`. When installed via `go install` or npm, `mcpsense version` shows `mcpsense vv0.2.1` (double "v"). This happens because `runtime/debug.ReadBuildInfo()` returns `v0.2.1` (with "v" prefix) and the display code prepends another "v".

## What to do

Open `cmd/mcpsense/main.go`. Find the `init()` function that has the `debug.ReadBuildInfo()` fallback. It looks something like this:

```go
func init() {
    if version == "dev" {
        if info, ok := debug.ReadBuildInfo(); ok && info.Main.Version != "" && info.Main.Version != "(devel)" {
            version = info.Main.Version
        }
    }
}
```

Change it to strip the leading "v" from the Go module version:

```go
func init() {
    if version == "dev" {
        if info, ok := debug.ReadBuildInfo(); ok && info.Main.Version != "" && info.Main.Version != "(devel)" {
            v := info.Main.Version
            if len(v) > 0 && v[0] == 'v' {
                v = v[1:]
            }
            version = v
        }
    }
}
```

Also search the entire file for any other place where version is set or formatted. Check if GoReleaser's ldflags already sets version with a "v" prefix. Search for `-ldflags` in `.goreleaser.yml` and in `Makefile`. If ldflags sets version as `v0.2.1` (with "v"), strip it there too, OR change the display code to not prepend "v". Pick one consistent approach:

- Either version variable always stores WITHOUT "v" prefix (like `0.2.1`) and display code adds "v"
- Or version variable always stores WITH "v" prefix (like `v0.2.1`) and display code does not add "v"

Check how version is displayed. Search for where `version` is printed. It might be in `cmd/mcpsense/main.go` (a version command) and in `internal/report/cli.go` (the header box). Look for patterns like `fmt.Sprintf("v%s", version)` or `"mcpsense v" + version`. Make sure only one "v" appears in the final output everywhere.
