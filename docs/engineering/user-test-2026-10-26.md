# Published 0.4.1 user walkthrough — 26 October 2026

## Outcome

No functional blocker was observed in the tested public CLI journeys. Fresh npm and Go installations, first scans, fixes, reports, permissions, updates and failure handling worked. This run also found customer-facing documentation gaps. The repository and npm README sources still described the published release as a candidate; this change corrects that wording and the pinned installation examples. The live website still advertises 0.3.0 and overstates coverage, so the complete public onboarding experience is not yet consistent.

This is a product walkthrough of the actual public package, not just a source test run. Windows used Node.js 22.23.4 and Go 1.27.3; Linux archive installation ran under Ubuntu/WSL. macOS and other physical Windows configurations were not freshly exercised in this run. Earlier hosted CI results are separate evidence.

## Confirmed onboarding gaps

1. **Repository release wording:** README called 0.4.1 a follow-up candidate and still pinned 0.4.0 in examples after both public channels reached 0.4.1. Corrected in the README sources in this change; scanner behavior and package version are unchanged.
2. **Published npm archive documentation:** its bundled README retains the old candidate wording. Correcting npm/README.md in Git does not change the immutable 0.4.1 tarball or automatically update npm's displayed README. No package was republished in this test. This is a documentation inconsistency, not an installation failure.
3. **Website promises:** an uncached-request HTTP 200 snapshot of https://mcpsense.site/ still advertised v0.3.0, an old Action tag, 39 checks and full attack-surface/dependency coverage. Current CLI documentation explicitly excludes runtime tool results, host authorization/session isolation and general semantic understanding; explicit npm lockfile selection is required for dependency inventory. The website needs updated release/setup text and bounded claims. Its deployment source was not present in this checkout or the accessible MCPSense repository branches; no website deployment was changed.
