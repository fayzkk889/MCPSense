# Security policy

MCPSense accepts vulnerability reports for the latest stable release and the
current default branch. Check the [release page](https://github.com/fayzkk889/MCPSense/releases/latest)
for the latest stable version.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/fayzkk889/MCPSense/security/advisories/new)
for vulnerabilities in MCPSense, including cases where it may execute untrusted
code or disclose sensitive data. Include the MCPSense version, operating system,
command and flags, a minimal synthetic reproduction, and the potential impact.
Remove credentials, private server URLs, and customer data before submitting.

Use [GitHub Issues](https://github.com/fayzkk889/MCPSense/issues) for ordinary
bugs and questions. Report vulnerabilities in third-party MCP servers privately
to their maintainers.
